# Apache Airflow Learning

This repository is where I document my Apache Airflow learning journey. I use it to maintain my syllabus, save notes, practice concepts, write code, and track what I have learned.

## What I'm Learning

- Apache Airflow fundamentals and architecture
- DAGs, tasks, operators, and sensors
- Scheduling workflows and managing task dependencies
- Building data pipelines using Python, SQL, and APIs
- XCom, hooks, connections, and variables
- Dynamic DAGs and advanced Airflow concepts
- Testing, debugging, logging, and monitoring
- Integrating Airflow with databases, Docker, and Kubernetes
- Deploying and managing Airflow in production
- Building real-world projects and preparing for interviews

## Repository Structure

I organize my learning materials into separate folders so I can easily find notes, code examples, exercises, and projects.

- `01_fundamentals/` – Basic concepts and architecture
- `02_installation_setup/` – Installation and environment setup
- `03_core_concepts/` – DAGs, tasks, and operators
- `04_workflows/` – Scheduling and task dependencies
- `05_data_pipelines/` – Practical pipeline implementations
- `06_advanced_airflow/` – Advanced concepts and techniques
- `07_integrations/` – Databases, Docker, and Kubernetes
- `08_testing_monitoring/` – Testing, logging, and debugging
- `09_deployment_production/` – Deployment and production practices
- `10_projects/` – Hands-on projects
- `11_interview_preparation/` – Interview questions and answers

## My Learning Approach

I learn each concept, write notes in my own words, implement practical examples, and save the code in this repository. I also maintain a learning tracker to monitor my progress and identify topics that need more practice.
