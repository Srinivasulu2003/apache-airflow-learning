# 01 - Airflow Fundamentals

In this section, I am learning the fundamentals of Apache Airflow. I will understand what Airflow is, why it is used, how it works, and its core concepts before moving to advanced topics.

## What I Will Learn

- What is Apache Airflow?
- Why do we need Apache Airflow?
- What is workflow orchestration?
- Airflow architecture and its components
- DAGs (Directed Acyclic Graphs)
- Tasks, operators, and task dependencies
- How an Airflow workflow executes
- Real-world use cases of Airflow
